🔧 Guia: Como Liberar as APIs

Siga estes passos para permitir que o sistema acesse as APIs de busca

1 Abra o Menu do Claude

No canto superior da janela do Claude Desktop, clique no menu (pode ser três linhas horizontais ☰ ou seu ícone de usuário)

2 Navegue até as Configurações

Procure por uma destas opções (dependendo da tradução):

Configuração de inferência ou Inference configuration ou Configurações ou Settings
3 Entre em Capacidades/Capabilities

Dentro das configurações, procure e clique em:

Capacidades → Restrições gerais

OU em inglês:

Capabilities → General restrictions
4 Encontre "Hosts Permitidos"

Procure pelo campo chamado:

  • "Hosts de saída permitidos"
  • ou "Allowed egress hosts"

É um campo de texto onde você pode adicionar URLs

5 Cole os Hosts das APIs

No campo, adicione estas linhas (pode copiar e colar todas de uma vez):

api.cnpja.com cnpja.com www.receitaws.com.br api-publica.datajud.cnj.jus.br opencnpj.org api.opencnpj.com
6 Aplicar e Reiniciar

Clique no botão:

Aplicar mudanças / Apply Changes

Quando pedir para reiniciar, clique em "Reiniciar Agora" ou "Restart Now"

✅ Pronto! Depois que o Claude reiniciar, volte para http://localhost:5000 no navegador e tente fazer a busca novamente.
⚠️ Lembre-se: Você precisa manter o terminal aberto com o comando python servidor_web.py rodando. Se fechou, abra novamente e rode o comando.

Caminho Visual Resumido:

Menu → Configurações → Capacidades → Restrições Gerais → Hosts Permitidos
